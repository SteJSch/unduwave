Setting Undulator Parameter

We give the K-parameters and the B-Amplitudes are calculated from there For Horizontal mode only, set Bz=K_para_z=0, shift=0 For Vertical mode only, set By=K_para_y=0, shift=0 For Circular mode, set By=Bz -> K_para_z=K_para_y, shift=0.25
